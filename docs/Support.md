# Glancemark Support

Glancemark requires an Apple Silicon Mac with macOS 27 or later.

Open a Markdown document using File → Open. Use Source to edit the plain text. To browse related files, use the document options menu → Choose Folder.

To preview a file in Finder, select it and press Space. If Glancemark’s preview does not appear, check System Settings → General → Login Items & Extensions → Quick Look. The preview may need you to prepare related images from the app using the document options menu.

For help or to report a bug, use [Glancemark’s GitHub Issues](https://github.com/Kian-hdr/glancemark/issues). Include your macOS version, Glancemark version, and steps to reproduce. Share only sample files you can make public.
