Renderer_Notices.txt contains the governing package text and npm integrity record for each discovered package. Some files include multiple license options or source notices. Glancemark does not change those terms. The assets in the shipped JavaScript files must match the pinned upstream distributions and stated grammar combination before publication.

The release owner still checks any added assets, font or trademark material, generated binaries, network disclosures and test fixture origins at the release commit. Public README media used for testing should remain referenced by pinned URLs unless its redistribution permission is established.
